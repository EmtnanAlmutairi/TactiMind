# مشروع TactiMind

## نظرة عامة
مشروع TactiMind هو نظام متكامل لتحليل تكتيكات المنافسين في كرة القدم باستخدام تقنيات الذكاء الاصطناعي. يقوم النظام بتحليل فيديوهات المباريات وتتبع اللاعبين والكرة، وكشف الأحداث المهمة، ودمج هذه المعلومات مع الإحصاءات التاريخية لتقديم تحليل تكتيكي شامل.

## المكونات الرئيسية

### 1. نموذج تتبع اللاعبين والكرة (TrackLab)
نموذج يستخدم TDEED (من مستودع dude.k) لتتبع مواقع اللاعبين والكرة في فيديوهات المباريات. يعتمد النموذج على تقنيات متقدمة للرؤية الحاسوبية وتم تدريبه على مجموعة بيانات SoccerNet لتحقيق دقة عالية في تتبع اللاعبين والكرة في ظروف مختلفة.

### 2. نموذج كشف الأحداث (Event Detection)
نموذج يستخدم شبكة TSM للتعرف على الأحداث المهمة في المباراة مثل التمريرات والتسديدات والأهداف.

### 3. وحدة دمج البيانات (Fusion)
سكريبت Python (`fusion.py`) يقوم بدمج بيانات التتبع وبيانات الأحداث مع الإحصاءات التاريخية لإنتاج تحليل تكتيكي شامل. يتضمن:
- تحليل أنماط الحركة والمواقع
- تحديد نقاط القوة والضعف التكتيكية
- اقتراح تكتيكات مضادة

### 4. خط أنابيب المعالجة (Pipeline)
يربط جميع المكونات معاً في تدفق عمل متكامل:
1. تتبع اللاعبين والكرة
2. كشف الأحداث
3. دمج البيانات وتحليلها
4. تقديم النتائج عبر واجهة برمجة التطبيقات

### 5. واجهة المستخدم React/WebGL
واجهة مستخدم تفاعلية تعرض التحليلات التكتيكية في الوقت الفعلي على خريطة ثلاثية الأبعاد.

## كيفية الاستخدام

### 1. إعداد المشروع
```bash
# استنساخ المستودع
git clone https://github.com/SuhailSaif1/TactiMind.git
cd TactiMind

# تثبيت المتطلبات
pip install sportsipy

# تنفيذ أوامر مانوس (بعد تحديث المعلومات الشخصية)
./manus_commands.sh

# ربط واجهة المستخدم
./ui_integration.sh
```

### 2. استخدام نموذج تتبع اللاعبين dude.k
```bash
# معالجة فيديو مباراة لتتبع اللاعبين والكرة
python models/track_lab/dude_k_integration.py /path/to/match_video.mp4 [/path/to/model.pt]
```

### 3. جلب البيانات التاريخية
```bash
# جلب البيانات التاريخية لفرق محددة
python scripts/historical_stats_fetcher.py --teams Barcelona Real_Madrid --years 2023 2024 --format csv
```

### 4. تشغيل واجهة المستخدم
```bash
cd react-app
npm install
npm start
```

## الملفات الرئيسية

- `manus_commands.sh`: أوامر إنشاء ونشر خط أنابيب TactiMind على منصة مانوس
- `ui_integration.sh`: أوامر ربط واجهة المستخدم React/WebGL مع خط الأنابيب
- `scripts/fusion.py`: سكريبت دمج البيانات وتحليل التكتيكات
- `scripts/historical_stats_fetcher.py`: سكريبت جلب البيانات التاريخية من الإنترنت باستخدام حزمة sportsipy
- `models/track_lab/dude_k_integration.py`: سكريبت تكامل نموذج TDEED من مستودع dude.k لتتبع اللاعبين والكرة

## المتطلبات

- حساب على منصة مانوس مع ملف حوسبة مناسب
- Node.js و npm لتشغيل واجهة المستخدم
- Python 3.6+ للتطوير المحلي
- مفتاح API لمنصة مانوس
- حزمة sportsipy لجلب البيانات التاريخية (`pip install sportsipy`)
- متطلبات نموذج dude.k لتتبع اللاعبين والكرة
